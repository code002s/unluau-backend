About / API

About KYNX

KYNX (Kinetic Control v4) is a browser-based, multi-dialect Lua-family bytecode decompiler with a public HTTP API. Upload or paste compiled bytecode and get readable source back, no install needed.

Luau is the Lua-derived language used by Roblox. It adds type annotations, continue, compound assignment and its own bytecode format (versions 3 to 14). KYNX detects the bytecode version from the header and routes the chunk to the matching engine: bundled WASM for Luau v3 to v7 and an optional external backend for newer versions.

Supported languages

  • Luau / Roblox bytecode
  • Lua 5.1, 5.2, 5.3, 5.4, 5.5
  • LuaJIT 2.0 / 2.1 (2.0 depends on the backend)
  • MoonScript and Teal are catalogued: they compile to plain Lua, so upload the resulting Lua bytecode

POST /decompile

Send the Base64 of the bytecode file in script. Optional fields: dialect and options.

{
  "script": "<base64-encoded-bytecode>",
  "dialect": "luau",
  "options": { "naming": { "mode": "heuristic" } }
}

Success returns the decompiled source as plain text with status 200.

-- decompiled by kynx
print("hello")

GET /health

Use it to check that the site and the decompiler engine are up. It returns 200 when everything works and 502 when the engine is unreachable.

{
  "ok": true,
  "site": "kynx-site-v4",
  "maxBytes": 4194304,
  "upstream": { "ok": true, "engine": "kynx-multi-backend", "lua": true, "luajit": true, "luau": true }
}

Examples

cURL: JSON request.

curl -X POST https://kynx-site.pages.dev/decompile \
  -H "Content-Type: application/json" \
  -d "{\"script\":\"$(base64 -w0 script.luauc)\"}"

cURL: Base64 body with query parameters, and the health check.

curl -X POST "https://kynx-site.pages.dev/luau/decompile?renaming=RAW" \
  --data-binary "$(base64 -w0 script.luauc)"

curl -X POST https://kynx-site.pages.dev/konstant/decompile \
  -H "Content-Type: text/plain" --data-binary @script.luauc

curl https://kynx-site.pages.dev/health

JavaScript (browser or Node 18+).

const bytes = new Uint8Array(await file.arrayBuffer());
let bin = "";
for (let i = 0; i < bytes.length; i += 0x8000) bin += String.fromCharCode(...bytes.subarray(i, i + 0x8000));

const res = await fetch("https://kynx-site.pages.dev/decompile", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ script: btoa(bin) }),
});
if (!res.ok) throw new Error(res.status + " " + await res.text());
console.log(await res.text());

Roblox executor loader (compatible executors only, not plain Lua).

loadstring(game:HttpGet("https://kynx-site.pages.dev/loader.lua"))()
